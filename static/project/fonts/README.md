# Local portfolio typefaces

These web subsets use the same open-source typefaces as Sudip Sah's portfolio:

- Barlow Condensed (700, 800), from Google Fonts, used as `Attendly Display`.
- DM Sans (400, 500, 700), from Google Fonts, used as `Attendly Sans`.
- IBM Plex Mono (400), from Google Fonts, used as `Attendly Mono`.

The local WOFF2 files are Latin and punctuation subsets. Modified font family names use Attendly aliases; the original licenses and copyright notices are included in this directory. Files were obtained from the official Google Fonts API and fonts.gstatic.com. Local hosting keeps the webpage compatible with the Python application's same-origin content-security policy.
