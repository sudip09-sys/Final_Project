03 / BUILT WITH CARE

Convenience with
a human in the loop.

Recognition supports the administrator. Uncertain results do not mark attendance automatically.

Read the recognition approach
01

Consent is a choice.

Students can use manual attendance without enrolling a face. Enrolled templates can be withdrawn.

02

Keep less. Protect what stays.

Raw images are processed in memory. Stored face templates are encrypted with Fernet.

03

Know the prototype’s limits.

There is no liveness detection: a photo may pass recognition. Supervise the station and review results.

Administrator guide
Does this webpage recognize faces?

The interactive walkthrough simulates attendance using fictional students. The Python application provides actual camera capture and server-side face recognition after administrator sign-in.

Do I need to enroll a face to record attendance?

No. Administrators can add a student without a face image and record attendance manually with a verification note.

Will the free demo keep my records?

The current Render demo uses temporary SQLite storage, so data resets when the service restarts. Export CSV before leaving. The repository includes a MySQL configuration and instructions for connecting persistent storage.
