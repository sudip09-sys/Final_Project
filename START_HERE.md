# Start here

1. Read README.md for installation and the first attendance session.
2. Use Python 3.12 and run `pip install -r requirements.txt` in a virtual environment.
3. Run `python scripts/setup.py`, then `python scripts/run.py`.
4. Open http://127.0.0.1:5000 and use the password you created.

For MySQL, use the included Docker Compose instructions. The separately delivered ZIP contains no secret, default administrator password, enrolled face or production database.

The separately delivered submission ZIP includes PowerPoint, Word, PDF and video files. Other documentation is readable Markdown. Editable diagrams are in `docs/diagrams`. Tutorial captions and setup instructions are in `tutorials`.

GitHub publication and cloud runtime verification are separate from this downloadable build. See `docs/Release_Status.md` for the verified current status.
