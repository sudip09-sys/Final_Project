# Project tutorials

- `01_Setup.md`: Python installation, private configuration, startup and MySQL Docker steps.
- `02_Enrollment_Checkin.mp4`: actual application screen recording demonstrating optional face enrollment, explicit consent, class session creation, real image recognition, duplicate prevention, CSV export and the roster.
- `03_Manual_Withdrawal.mp4`: actual application screen recording demonstrating manual-only enrollment, manual verification, template withdrawal and session closure.
- `.srt` files contain the captions already burned into the MP4 videos.

Videos are silent, captioned walkthroughs slowed for readability. The face fixture is a public software test image. It is labeled Demo Participant and is not a real enrolled student. No raw portrait, embedding or real attendance record ships with the project.

The videos exercise image upload. Start camera uses the same backend recognition path, but physical webcam capture must be verified on your own demonstration device. This prototype does not implement liveness detection.
